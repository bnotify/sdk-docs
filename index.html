What BNotify provides

Capability Android iOS
Device registration Socket.IO + FCM token APNs token → REST API
System push UI Auto tray notifications APNs + optional NSE media
Click / dismiss analytics Built into SDK flow Host calls trackEvent
In-app messages Socket.IO campaigns Socket.IO campaigns
Expanded images / GIF BigPicture + GIF frames NSE attachments
Important

SDKs do not send pushes by themselves. Your BNotify backend delivers messages (Socket.IO / FCM on Android, APNs on iOS). The SDK registers the device, displays content, and reports events.
